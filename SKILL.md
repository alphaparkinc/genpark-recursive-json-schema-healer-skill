# GenPark Recursive JSON Schema Healer

## Description
Recursive JSON schema validator and autonomous healer repairing type mismatches, missing defaults, and broken LLM outputs.

## Compatibility
- MCP Version: 2025-12-11
- Python: >=3.10 (Standard Library only)
- Supported Platforms: Claude Desktop, Cursor, LobeChat, Smithery, MCP.Directory
